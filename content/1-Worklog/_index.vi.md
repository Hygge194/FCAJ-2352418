Worklog này ghi lại chi tiết tiến độ công việc và quá trình thực tập của em trong vòng **9 tuần** tại chương trình FCAJ. **Tuần 4:** [Khởi tạo dự án Backend Shopsflow, thiết lập Database và hoàn thiện Proposal](1.4-Week4/)

**Tuần 5:** [Triển khai bảo mật Spring Security JWT, phát triển API Category & Product](1.5-Week5/)

**Tuần 6:** [Phát triển API Cart, Order, xử lý tranh chấp dữ liệu (Optimistic Locking) và viết Unit Tests](1.6-Week6/)
